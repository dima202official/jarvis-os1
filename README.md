# Jarvis OS1 · Сайло

Статическая PWA. После включения Pages:
https://dima202official.github.io/jarvis-os1/

Safari → Поделиться → На экран «Домой».

Сфера — слушать и остановить. Алфавит с **Ё** по команде. Память в localStorage. Голос — спокойный русский.

Локальный агент (файлы, терминал, поиск) слушает только этот компьютер:

```
node agent/server.mjs
```

Открыть http://127.0.0.1:8787/jarvis-os1/ . Примеры: «выполни pwd», «прочитай файл README.md», «создай файл notes.txt текст привет», «найди погода в Берлине», «посчитай 2+2». Страница на GitHub Pages эти команды выполнить не может.
